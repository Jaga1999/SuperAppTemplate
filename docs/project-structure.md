# Project structure

Every folder and the files you are likely to open, with what they are for.

```text
.
├── backend/              Spring Boot BFF (its own deployable)
├── frontend/             Next.js product app + e2e tests (its own deployable)
├── keycloakify/          the Keycloak sign-in theme (React) ─┐ together: the Keycloak deployable
├── keycloak/             Keycloak image, realm, emails, extensions, legal ─┘
├── infra/                nginx edge (its own deployable) and the Postgres init script
├── scripts/              start.mjs (local run), init-project.mjs (new project)
├── docs/                 this documentation (+ images/)
├── .claude/              settings and skills for Claude Code
├── compose.yaml          the stack, production shape
├── compose.override.yaml development additions (debug ports on 127.0.0.1)
├── .env.example          every configuration variable with placeholders (copy → .env)
├── AGENTS.md / CLAUDE.md rules for AI coding agents
├── package.json          only for `npx github:<owner>/<repo>` (the project generator)
└── README.md · LICENSE · .gitignore · .gitattributes · .dockerignore
```

## Root files

| File | Purpose |
|---|---|
| `compose.yaml` | Ten services, five private networks, five volumes, health checks, limits, hardening. Only nginx publishes a port |
| `compose.override.yaml` | Loaded automatically in development: publishes debug ports (DBs, Redis, Kafka, Keycloak admin, Mailpit, backend) on 127.0.0.1 |
| `.env.example` | Template for `.env` (the only place secrets live; `.env` is git-ignored) |
| `.gitignore` / `.gitattributes` | One of each for the whole repository (LF line endings, binary JARs and images) |
| `.dockerignore` | Keeps `node_modules`, build output and `.env` out of the root build context (Keycloak image) |
| `AGENTS.md` | Rules for AI agents: guardrails, conventions, commands, definition of done |
| `CLAUDE.md` | Claude Code specifics (imports AGENTS.md) |
| `package.json` | Lets `npx github:…` run the generator. Not part of the app; removed in generated projects |

## `keycloakify/`

Details: [keycloak.md](keycloak.md#2-how-keycloakify-turns-react-into-a-keycloak-theme).

## `keycloak/`

| Path | Purpose |
|---|---|
| `Dockerfile` | Four stages: theme JAR, extensions, optimized Keycloak build, runtime |
| `realm/superapp-realm.json` | The realm, imported on first start |
| `themes/superapp-email/` | Email theme: `email/html/*.ftl`, `email/messages/messages_en.properties`, `theme.properties` |
| `extensions/` | Gradle project: Kafka event listener, legal-consent required action (+ test) |
| `legal/` | Terms and Privacy Policy with the `version` users accept |

## `infra/`

| Path | Purpose |
|---|---|
| `nginx/Dockerfile` | Edge image (build context: `infra/nginx/`) |
| `nginx/nginx.conf` | Global settings: logs without query strings, gzip, rate-limit zones |
| `nginx/templates/superapp.conf.template` | Routing (`/` → frontend; `/api`, `/oauth2`, `/login/oauth2`, `/auth` → backend), limits, blocked back-channel path |
| `postgres/init/01-database.sh` | Runs once per Postgres server: creates the database and its non-superuser owner, locks down the `public` schema |

## `.claude/`

| Path | Purpose |
|---|---|
| `settings.json` | Allowed and confirm-first commands; reading `.env` and keys is denied |

## Where do I change…?

| I want to change | File(s) |
|---|---|
| Product name everywhere | Generate a new project ([template.md](template.md)) |
| Landing page text | `frontend/src/views/landing.tsx` |
| Colors, fonts | `frontend/src/styles/globals.css` **and** `keycloakify/src/styles/globals.css` |
| Logo | `frontend/src/components/ui/brand/logo.tsx`, `keycloakify/src/components/ui/brand/logo.tsx`, `frontend/src/app/icon.svg` |
| A signed-in page | `frontend/src/views/*` + route in `frontend/src/app/app/*` |
| Sign-in page texts | `keycloakify/src/login/i18n.ts` |
| Email texts | `keycloak/themes/superapp-email/email/messages/messages_en.properties` |
| Terms / Privacy | `keycloak/legal/*.md` **and** `frontend/legal/*.md` |
| Roles, password policy, token lifetimes | `keycloak/realm/superapp-realm.json` (then reset local data) |
| An API endpoint | `backend/src/main/java/com/superapp/<feature>/internal/*Controller.java` + its `docs/*ApiDocs.java` |
| Database schema | new `backend/src/main/resources/db/migration/V<n>__*.sql` |
| Rate limits | `infra/nginx/nginx.conf` (zones) and the template (bursts) |
| Ports | `compose.override.yaml` |

More recipes: [customization.md](customization.md).
